# 1.0.0 Review 记录

本次核对范围为 Zadix Android 项目。旧 Windows 工具仅复核了与 Zadix 恢复记录相关的测试。

| 路径 | 核对结果 |
| --- | --- |
| 规则导入、导出与本机开关 | 核对文件大小与目录限制、完整解析后原子替换、系统分享、Android 包可见性和开关状态所有权。 |
| 实时跳过、关闭确认和底部提示 | 核对无障碍事件、活动窗口、暂停、动作提交、关闭证据和提示清理。百度网盘使用已知版本与页面特征，其他普通应用仍按动作回执显示。 |
| App、磁贴、WebView 和更新 | 核对私有 IPC、权限入口、总开关、分类分页、写入回执、版本比较和 GitHub 更新入口。 |
| 系统清理、配对与恢复 | 核对只读规则、显式配对、回执及恢复前校验。无线 ADB 使用回环地址。当前没有开放系统配置写入。 |
| 构建与发行 | 核对独立仓库范围、版本、发行签名、发布内容及第三方源码声明。 |

修复了导入规则的任选匹配过早退出、未知动作回退到点击、QQ 复查前过早记录动作、恢复入口文案过时以及版本未读取时的更新比较。包可见性改用 Android 的桌面应用和已知包查询。新增关闭证据测试覆盖广告仍在、目标页缺失、窗口消失和观察超时。

Android 真机上的应用目录、磁贴、百度网盘与底部浮层需单独验收。归因不明确的动作仍显示「已提交 · 结果未确认」。

验证记录：40 项 Android JVM 测试、11 项电脑端恢复测试、Android Release Lint 与 Release 构建通过。浏览器在 390 px 和 1440 px 宽度检查分类列表、单应用开关回执、错误重试与资料包导入导出。Lint 仍提示 WebView JavaScript、回环无线 ADB 依赖的 TLS 实现以及应用进程长期持有的 Context 等警告。相应入口的限制已按代码复核。
