# Zadix 资料包

规则库接受单个 `.zadixsource` 文件。Android 完整校验规则和启用配置后再替换当前导入的资料包；内置规则、无障碍授权、全局启停意愿和系统清理状态单独保存。桌面预览只读资料包结构和来源摘要，不执行 Android 规则。

版本 1 是一个 ZIP 容器（文件和解压内容各不超过 16 MiB，最多 128 个文件），只允许以下条目：

- `manifest.json`：`{"format":"zadixsource","version":1}`。
- `profile.json`：`sources`（来源 ID、顺序和启用状态）、`groups`（分组或应用覆盖项和排除项）、`categories`（分类开关）。
- `rules/1.json5` 起连续编号的规则正文。每个启用来源必须有对应的正文；禁用项可以只有配置。来源 ID 唯一。

开屏引擎只运行名称以「开屏广告」开头且通过选择器校验的规则组。QQ 腾讯文档小程序仍由内置专用规则负责。私人总包不随应用或源码分发，用户通过保存或分享在设备之间迁移。旧版应用内已有的配置由升级兼容入口读取，再按新格式分享。
